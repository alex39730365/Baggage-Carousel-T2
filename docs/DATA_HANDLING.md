# 데이터 취급·보안 메모

## 성격

이 앱은 **공항 수하물 캐러셀·운항 관련 공개/준공개 데이터**를 표시한다. CSV 보내기는 그 데이터를 사용자 기기에 파일로 저장할 뿐, 별도 서버에 업로드하지 않는다.

## CSV·공유 시 유의

- 메일·메신저·터널 URL로 넘기면 **전송 경로·수신자**에 따라 유출 범위가 달라진다. 사내 규정(보존 기간, 전달 대상)을 따른다.
- 브라우저 **감사 로그**(`sessionStorage`, 키 `baggage-client-audit-v1`)는 같은 탭 세션에서 최근 수십 건만 유지되며, **탭을 닫으면 사라진다.** 법적·운영 감사가 필요하면 **서버·게이트웨이 로그**와 병행해야 한다.
- Vercel Analytics를 쓰는 경우 `csv_export` 이벤트에 **행 수·날짜·탭 키**만 전달한다(편명·슬롯 raw 전체는 보내지 않음).

## API 키

- 로컬 개발용 키는 저장소에 두지 말고 `.env` 로 관리한다.
- 운영 배포는 Vercel 환경 변수 등에 **서버 측** 키를 둔다.

## 권장

- 외부 공유 전 **최소 필요 데이터만** 포함했는지 검토한다.
- 터널·임시 URL은 **업무 종료 후** 닫는다.
